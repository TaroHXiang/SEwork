Admin Manual

单细胞相似性检索系统管理员手册

本手册面向管理员和超级管理员，说明用户管理、数据集治理、索引管理、任务监管和审计检查等后台操作。

1. 角色说明

  • user：普通用户，只能使用自己的数据与索引
  • admin：管理员，可管理普通用户相关资源
  • super_admin：超级管理员，可进一步管理管理员账号
普通用户无法自助提升为管理员。管理员账号应由项目维护者预置和分发。

2. 管理总览

管理员登录后，在历史页可看到 Admin Dashboard。该区域用于统一查看系统运行情况。

总览区域重点指标包括：

  • 用户总数、启用账号、停用账号
  • 数据集总数、索引总数
  • 失败任务数、进行中任务数
  • 管理员数量

同时还会展示索引类型分布、距离度量分布、构建趋势和用户索引 Top 10 图表。

3. 用户管理

3.1 创建用户

  • 填写账号、显示名、邮箱和密码
  • 默认可创建普通用户
  • 只有超级管理员可以直接创建管理员

3.2 修改用户

  • 可修改显示名、邮箱、启用状态
  • 可对普通用户进行启用或停用
  • 超级管理员可在 user 与 admin 之间切换角色

3.3 重置密码

当用户遗忘密码或账号交接时，可在后台执行密码重置。

3.4 删除用户

删除用户前应确认其索引和数据集是否仍被需要。系统会联动删除该用户相关索引记录。

4. 数据集管理

管理员可以查看所有数据集的来源、格式、细胞数、向量维度和状态。

  • 按所属用户排查数据归属
  • 识别失效数据路径或异常格式
  • 删除不再使用或错误导入的数据集
删除数据集前请先确认是否存在关联索引。系统会联动处理相关索引，但仍建议先完成沟通与备份。

5. 索引管理

  • 查看索引所属用户、关联数据集、索引类型、距离度量和构建参数
  • 强制激活某个索引，帮助用户恢复工作环境
  • 删除错误、失效或不再使用的索引

适用场景：

  • 用户误操作导致活跃索引切换错误
  • 容器内对应索引集合已经失效，需要清理后台元数据
  • 课程演示时需要统一切换到指定索引

6. 构建任务监管

管理员可查看索引构建任务的：

  • 所属用户
  • 目标数据集
  • 索引名称
  • 状态与阶段
  • 更新时间

当出现构建失败时，可结合错误信息和更新时间判断问题是否来自数据文件、容器连接或配置不一致。

7. 审计日志

审计日志用于记录关键后台操作，便于答辩展示、责任追踪和问题回溯。

典型记录包括：

  • 创建用户
  • 修改角色
  • 停用或启用账号
  • 重置密码
  • 删除数据集
  • 删除或强制激活索引

8. 管理员初始化

若系统尚无管理员账号，可由部署者在项目根目录执行：

python scripts/bootstrap_admins.py

脚本默认会处理以下账号：

  • admin01
  • admin02
  • admin03
  • admin04

其中第一个账号默认会被设置为 super_admin。

9. 操作建议

  • 先看总览，再进入用户、数据集和索引细查问题
  • 删除用户或数据集前，先确认是否仍在演示流程中使用
  • 对管理员账号的增删改操作，尽量由超级管理员执行
  • 出现异常构建任务时，先检查 MySQL、FAISS 和数据挂载路径
  • 如需面向普通用户答疑，请优先引导其查阅用户手册
