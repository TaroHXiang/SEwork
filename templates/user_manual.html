1. 系统概览

系统用于对单细胞数据进行向量化相似检索。你可以输入数据文件路径，先检查数据内容，再根据场景构建 FAISS 索引，最后按细胞 ID 或向量检索相似细胞。

你可以完成的事情

  • 检查数据集规模、向量维度和元数据字段
  • 查看 UMAP 预览、统计分布和细胞详情
  • 构建 HNSW、IVF、PQ 三类索引
  • 按细胞 ID 或向量执行 Top-K 检索
  • 用元数据条件过滤检索范围

使用前提

  • 项目服务已由部署者启动
  • 你已获取普通用户账号，或可自行注册
  • 数据文件使用 `.csv` 或 `.h5ad` 格式
  • 数据路径对系统和 FAISS 服务均可访问

2. 登录与入口

  1. 打开系统首页。
  2. 输入账号和密码。
  3. 如无账号，可先注册普通用户。
  4. 登录后进入“数据集入口”页面。

登录后你会看到两类入口：

  • 我的历史索引：进入你以前构建过的索引
  • 录入新数据集：从新的数据文件开始分析流程

如果当前账号具有管理员角色，页面上还会额外显示管理员工作台入口，但普通分析流程不受影响。

3. 数据准备

3.1 支持的数据格式

  • .csv
  • .h5ad

3.2 CSV 基本要求

  • 必须包含 cell_id 列
  • 所有向量列必须以 v 开头，例如 v1、v2
  • 其他列会被当作元数据

3.3 H5AD 基本要求

  • 细胞 ID 来自 obs_names
  • 系统优先读取 obsm["X_pca"] 作为向量
  • 若无 X_pca，系统会尝试使用 X

3.4 推荐操作

  1. 先在历史页输入数据路径。
  2. 进入核心页面后点击“检查数据”。
  3. 确认数据集摘要、向量维度和可用元数据无误。
  4. 再决定是否构建索引。

4. 索引构建

系统支持以下索引类型：

  • HNSW：召回率通常较高，查询速度快，适合中小到中大型数据集
  • IVF：适合更大规模数据，可通过 NList 和 NProbe 平衡速度与召回
  • PQ：压缩率高，适合内存敏感场景，但精度可能下降

常见配置项：

  • Distance Metric：选择相似度度量方式
  • HNSW M / EF Construct / EF Search
  • IVF NList / NProbe
  • PQ Compression
构建大数据集时，建议使用异步构建。这样系统会在后台执行任务，并在页面中持续刷新进度。

5. 相似检索

5.1 按 ID 查询

  • 输入一个已存在的细胞 ID
  • 设置 Top-K
  • 点击“开始查询”

5.2 按向量查询

  • 输入逗号分隔的向量
  • 设置 Top-K
  • 点击“开始查询”

5.3 元数据过滤

你可以在查询前先设置过滤条件，例如：

  • 细胞类型
  • 疾病状态
  • 年龄组
  • 性别
  • 组织来源
  • 捐赠者 ID

5.4 检索评估

打开 Enable ANN vs Exact evaluation 后，系统会展示 ANN 与精确检索的对比指标，用于分析检索效果。

6. 可视化结果

结果展示区会联动呈现以下内容：

  • 数据集概览摘要
  • 细胞类型分布统计
  • 样本来源分布统计
  • 数据质量统计
  • UMAP 散点图
  • 检索结果表格
  • 单个细胞详情

UMAP 区支持预览层级切换、颜色模式切换、结果高亮和导出 CSV/JSON。

7. 历史索引管理

  • 在历史页查看你已经构建过的索引
  • 点击卡片直接进入对应数据集页面
  • 切换激活索引后，再执行查询
  • 不再使用的索引可以删除

8. AI 助手

AI 助手会结合当前数据集，帮助你理解不同索引类型的特点和参数选择逻辑。适合用来回答：

  • 当前数据集更适合 HNSW、IVF 还是 PQ
  • 距离度量该如何选择
  • 如何平衡速度、召回和内存
如果系统未配置 AI 服务密钥，AI 助手入口可能存在但无法正常返回答案，这不会影响普通检索流程。

9. 常见问题

9.1 检查数据时报错“找不到文件”

请确认数据路径是否正确，并确保该路径对系统运行环境可访问。

9.2 构建索引失败

优先联系部署者检查 FAISS 服务是否已启动，以及数据文件是否被容器正确挂载。

9.3 查询结果为空

请检查是否已成功激活索引，以及当前过滤条件是否过于严格。

9.4 无法使用管理员功能

管理员功能需要管理员或超级管理员账号；普通用户不会显示相应操作入口。
