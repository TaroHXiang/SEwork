1. 系统概览

系统面向单细胞数据分析场景，支持在同一界面中完成数据检查、FAISS 索引构建、相似检索、UMAP 可视化和 AI 辅助分析。

你可以完成的事情

  • 检查数据集规模、向量维度和元数据字段
  • 查看 UMAP 预览、统计分布和细胞详情
  • 构建 HNSW、IVF、PQ 三类索引
  • 按细胞 ID 或向量执行 Top-K 检索
  • 用元数据条件过滤检索范围
  • 用自然语言查询候选细胞并获取解释依据
  • 查看 ANN 与 Exact 的评估结果

使用前提

  • 项目服务已由部署者启动
  • 你已获取普通用户账号，或可自行注册
  • 数据文件使用 `.csv` 或 `.h5ad` 格式
  • 数据路径对系统和 FAISS 服务均可访问
  • 如需使用 AI 助手，部署者需提前配置 `.env` 和知识索引

2. 登录与入口

  1. 打开系统首页。
  2. 输入账号和密码。
  3. 如无账号，可先注册普通用户。
  4. 登录后进入“数据集入口”页面。

登录后你会看到两类入口：

  • 我的历史索引：进入你以前构建过的索引
  • 录入新数据集：从新的数据文件开始分析流程

如果当前账号具有管理员角色，页面上还会额外显示管理员工作台入口，但普通分析流程不受影响。

3. 数据准备

3.1 支持的数据格式

  • .csv
  • .h5ad

3.2 CSV 基本要求

  • 必须包含 cell_id 列
  • 所有向量列必须以 v 开头，例如 v1、v2
  • 所有向量列的维度必须一致，且内容应为数值
  • 其他列会被当作元数据，例如 cell_type、disease、tissue

3.3 H5AD 基本要求

  • 细胞 ID 来自 obs_names
  • 系统优先读取 obsm["X_pca"] 作为向量
  • 若无 X_pca，系统会尝试使用 X
  • 常见可用元数据来自 obs，如 cell_type、disease、tissue

3.4 推荐操作

  1. 先在历史页输入数据路径。
  2. 进入核心页面后点击“检查数据”。
  3. 确认数据集摘要、向量维度和可用元数据无误。
  4. 再决定是否构建索引。
如果数据文件位于项目目录之外，部署者需要额外为 FAISS 服务配置挂载路径；否则数据检查可能成功，但索引构建会失败。

4. 索引构建

系统支持以下索引类型：

  • HNSW：召回率通常较高，查询速度快，适合中小到中大型数据集
  • IVF：适合更大规模数据，可通过 NList 和 NProbe 平衡速度与召回
  • PQ：压缩率高，适合内存敏感场景，但精度可能下降

常见配置项：

  • Distance Metric：选择相似度度量方式
  • HNSW M / EF Construct / EF Search
  • IVF NList / NProbe
  • PQ Compression

系统同时支持以下距离度量：

  • cosine
  • ip
  • l2
  • pearson
构建大数据集时，建议使用异步构建。系统会在后台执行任务，并在页面中持续刷新进度；如果对同一数据集重复使用相同参数构建，系统可能直接复用已有索引。

5. 检索与评估

5.1 按 ID 查询

  • 输入一个已存在的细胞 ID
  • 设置 Top-K
  • 点击“开始查询”

5.2 按向量查询

  • 输入逗号分隔的向量
  • 设置 Top-K
  • 点击“开始查询”

5.3 元数据过滤

你可以在查询前先设置过滤条件，例如：

  • 细胞类型
  • 疾病状态
  • 年龄组
  • 性别
  • 组织来源
  • 捐赠者 ID

5.4 检索评估

打开 Enable ANN vs Exact evaluation 后，系统会展示 ANN 与精确检索的对比指标，用于分析检索效果。

  • precision_at_k
  • recall_at_k
  • overlap_count
  • ann_query_time_ms
  • exact_query_time_ms

6. 可视化结果

结果展示区会联动呈现以下内容：

  • 数据集概览摘要
  • 细胞类型分布统计
  • 样本来源分布统计
  • 数据质量统计
  • UMAP 散点图
  • 检索结果表格
  • 单个细胞详情

UMAP 区支持预览层级切换、颜色模式切换、结果高亮和导出 CSV/JSON。

7. 历史索引管理

  • 在历史页查看你已经构建过的索引
  • 点击卡片直接进入对应数据集页面
  • 切换激活索引后，再执行查询
  • 不再使用的索引可以删除
  • 管理员用户还会看到额外的 Admin Dashboard 入口

8. AI 助手

系统中的 AI 能力分为两类，都会结合当前数据集上下文工作：

8.1 索引顾问

  • 回答当前数据集更适合 HNSW、IVF 还是 PQ
  • 解释距离度量如何选择
  • 帮助平衡速度、召回和内存开销

8.2 细胞自然语言分析

这不是单纯聊天，而是一条结合知识库和数据集结果的分析链路。系统会：

  1. 解析问题中的 cell_type、disease、tissue 等线索
  2. 检索本地知识库中的概念、marker 和说明文档
  3. 结合当前活动索引或当前候选结果召回相关细胞
  4. 融合知识证据与数据集证据，给出解释和下一步建议

适合提问：

  • 某类 cell_type 的常见 marker gene 是什么
  • 肝脏、纤维化或免疫细胞相关问题涉及哪些候选细胞
  • 为什么这些细胞会被召回，下一步该做什么分析
若未配置 ZHIPU_API_KEY，索引顾问接口会不可用；细胞自然语言分析仍可运行，但会返回规则化回答。普通检索、索引构建和历史索引管理不受影响。

9. 常见问题

9.1 检查数据时报错“找不到文件”

请确认数据路径是否正确，并确保该路径对系统运行环境可访问。

9.2 构建索引失败

优先联系部署者检查 FAISS 服务是否已启动，以及数据文件是否被容器正确挂载。

9.3 查询结果为空

请检查是否已成功激活索引，以及当前过滤条件是否过于严格。

9.4 AI 助手回答不完整或不可用

请联系部署者检查是否已配置 ZHIPU_API_KEY，以及是否已提前执行 python scripts/build_knowledge_index.py --batch-size 256 --log-dir logs --resume 生成知识索引。若部署者怀疑环境或模型有问题，建议先运行 python scripts/build_knowledge_index.py --diagnose-only --log-dir logs 再正式构建。

9.5 无法使用管理员功能

管理员功能需要管理员或超级管理员账号；普通用户不会显示相应操作入口。
